# Déploiement Render

Le dépôt propose un Blueprint Docker à configurer dans Render (**New → Blueprint**). Autorisez l’accès à ce dépôt public, choisissez `main`, vérifiez la configuration, définissez `ADMIN_EMAIL` et un mot de passe admin fort, puis lancez le déploiement. Render fournit son URL publique après réussite du build. Configurez sauvegardes SQLite et politique de confidentialité avant usage réel.

Le modèle IA est chargé dans le navigateur à la demande. Le studio vidéo exporte une animation WebM locale, et non une génération vidéo IA réaliste.
